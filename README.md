# Barrage

Barrage bloque automatiquement sur vos réseaux sociaux les comptes d'une liste collaborative et open source.

- Site et installation : https://app-buildr.github.io/barrage/
- Télécharger la dernière version : [barrage.zip](https://github.com/app-buildr/barrage/releases/latest/download/barrage.zip)
- Code de l'extension : `extension/`
- Listes de comptes : `lists/`, voir [son README](lists/README.md) pour le format et pour proposer un compte

## Demander un retrait de la liste

Votre compte figure dans la liste et vous souhaitez en être retiré ? Écrivez à **barrage.app@protonmail.com** en indiquant le nom du compte (@nom). Seule la liste de X contient des comptes aujourd'hui.

Chaque demande reçoit une réponse dans un délai d'un mois maximum.
